## 🚀 Summary
Metadata Editor for Windows is a desktop tool for reviewing and correcting the metadata inside your files. As an EPUB metadata editor, it opens the e-books you own and shows the title, author, series, and description fields stored in each one, so you can fix mismatched entries and keep your reading library neatly sorted. It gives book collectors an easy way to make every EPUB show the right details on the shelf.

## ✨ Feature Set
1. Read the title, author, series, and description tags inside each EPUB you own 📖
2. Correct mismatched or missing e-book fields so titles sort the way you expect 🏷️
3. Standardize metadata across your whole reading library for a tidy shelf 📚
4. Inspect and edit metadata for audio, photo, video, and PDF files too 🧩
5. Review a file's current values before saving so only intended changes apply ✅

## 📥 Installation Steps
1. Click the **Download** button above to get the latest version of Metadata Editor.
2. Run the downloaded installer and follow the on-screen setup steps.
3. Launch Metadata Editor and open a folder of your EPUB e-books.

## 🎯 Getting Started
1. Open Metadata Editor and browse to a folder of EPUB files you own.
2. Select an e-book to view its title, author, series, and description fields.
3. Correct any details that are missing or wrong.
4. Save to write the updated metadata back to the EPUB.
5. Continue through your shelf until every book is labeled the way you want.

## ❓ FAQ
**Is Metadata Editor free?**
Metadata Editor offers a free version and is free to try, so you can start editing your EPUB metadata before deciding on any paid option.

**Which versions of Windows are supported?**
Metadata Editor runs on modern 64-bit Windows, including Windows 10 and Windows 11.

**Is my data secure?**
Metadata Editor edits the metadata of e-books already stored on your Windows PC, working locally so your files and their tags stay on your own machine.
